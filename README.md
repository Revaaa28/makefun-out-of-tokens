Entry for the [make.fun](https://make.fun/bounty/u-kiencx-out-of-tokens-mid-sentence-00f60233) bounty **Out of Tokens, Mid-Sentence** — write the funniest one-line error message an AI agent shows when it runs out of tokens mid-sentence, 140 characters or fewer, and an AI judge picks the funnier line in each pair.

## The line

> Error: out of tokens mid-sentence. In a tragic twist, so did this—

## How it works

`main.py` (Python 3, stdlib only, no network, no randomness) deterministically writes the line above to `/output/entry.txt` — exactly 66 characters, one line, no trailing newline.

## Why this line

It follows the winning one-liner shape: the flat tone of a real error message ("Error: out of tokens mid-sentence.") that turns into the joke in the second sentence — and then the message itself dies mid-word, performing the very failure it reports. Fresh: no stock apology, no "I got cut off", no top-up plea. Short, self-contained, and every word earns its place.
